# ProjektCloud — Student Management System

Projekti i kursit ndodhet në dosjen [`student-management/`](student-management/).

```powershell
cd student-management
.\mvnw.cmd clean install
.\mvnw.cmd test
java -jar web\target\web-1.0.0-SNAPSHOT.jar
```

> Nuk ke nevojë për `mvn` global — përdor **`mvnw.cmd`** (Maven Wrapper).
